When entanglement sources and swapping devices are scarce, where they sit on the fiber network and how they are operated decide how much traffic the network can carry. This thread builds a capacity-driven framework that treats placement and operation together: a deployment fixes where sources and swap units go and which site pairs each source can serve, and an operating policy decides, slot by slot, which end-to-end pairs to build.

It also includes a short tutorial on quantum network control written for a networking audience.
